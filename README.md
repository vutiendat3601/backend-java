# Backend Java

A collection of Java backend sample projects demonstrating common backend development concepts, distributed systems patterns, and best practices.

## 🎯 Purpose

This repository serves as a personal knowledge base and reference implementation for various backend engineering topics. Each subproject focuses on solving a specific problem or demonstrating a particular technique using real, runnable code.

The goal is to learn by building practical examples rather than relying solely on theory.

## 📚 Topics

Current and planned examples include:

* 🔒 Distributed Lock
* 🔐 Pessimistic Locking
* ⚡ Optimistic Locking
* 📄 Cursor-based Pagination
* 📨 Apache Kafka
* 🔄 Transaction Management
* 🌐 REST API Design
* ⚙️ Concurrency
* 🗄️ Database Performance
* ☁️ Distributed Systems Patterns

## 📁 Project Structure

```text
backend-java/
├── caching/
├── pagination/
├── distributedlocking/
├── relationaldatabaselocking/
├── kafka/
└── ...
```

Each project is self-contained and includes its own source code, configuration, and documentation.

## 🚀 Technologies

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Redis
